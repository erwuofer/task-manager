# Дизайн-документ: Task Manager

## 1. Загальна інформація

**Назва проєкту:** Task Manager  
**Тип програми:** консольний застосунок для роботи зі списком завдань.  
**Мова програмування:** Java 21.  
**Система збірки:** Maven.

Програма призначена для ведення простого списку особистих завдань. Користувач може додавати завдання, переглядати їх, позначати виконаними та видаляти. Дані зберігаються у JSON-файлі, тому список залишається після завершення програми.

## 2. Можливості та вимоги

### Функціональні вимоги

- Перегляд усіх завдань зі статусом виконання.
- Перегляд докладної інформації про завдання за його номером.
- Створення завдання через послідовний діалог у консолі.
- Позначення завдання виконаним.
- Видалення завдання.
- Автоматичне збереження змін та відновлення даних під час наступного запуску.
- Виведення переліку доступних команд.

### Режими роботи

Під час запуску можна вибрати один із двох режимів CLI:

- **Перегляд** — доступні команди `list`, `show` та `help`.
- **Керування** — доступні всі команди, зокрема створення, завершення та видалення завдань.

Режим можна вибрати через діалог під час запуску або передати аргументом `--view` чи `--manage`.

## 3. Архітектура програми

Застосунок поділений на три основні частини: представлення, бізнес-логіку та збереження даних.
`Main` створює потрібні об'єкти та зв'язує їх між собою. Шар Core не залежить від консолі або Gson. Він працює з інтерфейсом `TaskRepository`, а конкретну реалізацію цього інтерфейсу надає інфраструктурний шар.

## 4. Основні класи

| Клас або інтерфейс   | Призначення                                                                                           |
|----------------------|-------------------------------------------------------------------------------------------------------|
| `Main`               | Створює об'єкти програми та реєструє команди.                                                         |
| `Command`            | Спільний інтерфейс консольних команд.                                                                 |
| `CommandParser`      | Розбирає введений рядок на назву команди, аргументи та опції. Підтримує лапки для тексту з пробілами. |
| `CommandRegistry`    | Зберігає зареєстровані команди та знаходить їх за назвою.                                             |
| `CommandLoop`        | Приймає команди в циклі, запускає їх та показує помилки.                                              |
| `ModeSelector`       | Вибирає режим через аргумент запуску або діалог.                                                      |
| `TaskMode`           | Позначає режими перегляду та керування.                                                               |
| `Task`               | Зберігає номер, назву, опис і стан виконання завдання.                                                |
| `TaskService`        | Створює, знаходить, завершує та видаляє завдання. Після зміни передає оновлений список на збереження. |
| `TaskRepository`     | Визначає операції завантаження та збереження списку завдань.                                          |
| `JsonTaskRepository` | Реалізує `TaskRepository` за допомогою Gson та JSON-файлу.                                            |
| `TaskPresenter`      | Організовує діалог із користувачем і форматує інформацію про завдання.                                |
| `ConsoleDisplay`     | Читає введення та виводить текст у консоль.                                                           |

## 5. Консольний інтерфейс

Якщо програму запустити без аргументів, вона запропонує вибрати режим. Також режим можна вказати під час запуску:

| Аргумент       | Режим                                    |
|----------------|------------------------------------------|
| `--view`       | Перегляд завдань без команд зміни даних. |
| `--manage`     | Повне керування списком завдань.         |
| без аргументів | Вибір режиму через діалог.               |

У режимі перегляду доступні `help`, `list`, `show` та `exit`. У режимі керування доступні всі команди з таблиці нижче.

| Команда       | Дія                                                                                             |
|---------------|-------------------------------------------------------------------------------------------------|
| `help`        | Показати доступні команди.                                                                      |
| `list`        | Вивести завдання. Підтримує фільтр `--status all`, `--status pending` або `--status completed`. |
| `add`         | Створити завдання через діалог.                                                                 |
| `show <id>`   | Вивести назву, опис і статус завдання.                                                          |
| `done <id>`   | Позначити завдання виконаним.                                                                   |
| `delete <id>` | Видалити завдання.                                                                              |
| `exit`        | Завершити програму.                                                                             |

## 6. Обробка помилок

Програма повідомляє користувача, якщо введено невідому команду, неправильну кількість аргументів, некоректний номер або номер завдання, якого немає у списку. Порожня назва не дозволяється. Помилки читання чи запису файлу також передаються користувачу, а незбережена зміна не підміняє поточний список у `TaskService`.

## 7. Запуск і перевірка

Потрібні JDK 21 або новіший та Maven.

```bash
mvn test
mvn exec:java
```

За потреби режим можна передати під час запуску:

```bash
mvn exec:java -Dexec.args="--view"
mvn exec:java -Dexec.args="--manage"
```

Тести перевіряють основні операції `TaskService`, читання та запис JSON, розбір команд, вибір режиму й спільний сценарій роботи CLI. Тимчасові файли тестів створюються в окремих тимчасових папках, тому тестування не змінює робочий файл `data/tasks.json`.
